## Instructions for Contributors

1. Whenever a command, migration, sync payload, or test surprises you, append an entry below using the template.
2. You do not need to polish prose—record the exact file path, error message, or table name while it is fresh.
3. During periodic refreshes (see `handoff.md`), maintainers verify each entry against the codebase, merge it into its home document (`01`–`16`) with credit, and clear it from this queue.
